# מערכת ניהול פיננסי – דנה דרעי

אפליקציית ווב לניהול הכנסות, הוצאות ורווח של Dana Deri Beauty Studio.
דנה דרעי מזינה את הנתונים, והיועצת עוקבת ומבקרת.

- `app/`: גרסת הדמו. פותחים את `app/index.html` בדפדפן. אין צורך בהתקנה.
- `docs/אפיון.md`: מסמך האפיון, כולל ההחלטות שהתקבלו והשאלות הפתוחות.

בדמו הנתונים נשמרים בדפדפן (localStorage). אפשר לייצא ולייבא קובץ גיבוי.
